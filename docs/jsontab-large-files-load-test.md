# Нагрузочный тест jsontab v4

Дата — 21 ноября 2026 г. ТЗ — [просмотр больших JSON и JSONL](jsontab-large-files-spec.md).

**Стенд.** ASUS ROG Zephyrus G14 GA403UI, AMD Ryzen 9 8945HS (8 ядер, 16 потоков), 32 ГБ ОЗУ, NVMe Viper VP4300 2 ТБ. Windows 11 x64, сборка 26300. Плагин собран Free Pascal 3.2.3 для Win64.

**Тест-кейс.** Два файла UTF-8 размером ровно 1 ГиБ каждый. В JSON-массиве и JSONL один набор из 262 144 записей с уникальными ID, 64 сессиями, Unicode, вложенными значениями, записями на границах блоков и полем `late` у последних 64 записей. Для каждого файла подтвердили открытие, дождались первой страницы и завершения индексации, перешли в середину и конец, вернулись назад, сгруппировали по `session` и отфильтровали `late = needle` по группе и по всему файлу. Проверили открытие записи в Text и поиск в текущем представлении.

| Метрика | JSONL | JSON |
|---|---:|---:|
| От подтверждения до первых 256 строк | 168 мс | 149 мс |
| Полная индексация, от подтверждения | 4,78 с | 4,48 с |
| Первые 100 МиБ, замер рабочего потока | 0,52 с | 0,45 с |
| Первый переход в середину / конец | 109 / 108 мс | 118 / 99 мс |
| Возврат в начало / повторный переход в середину | 15 / 15 мс | 20 / 20 мс |
| Группировка по `session` | 9,23 с | 10,37 с |
| Фильтр в группе `s00` / по всему файлу | 0,31 / 8,30 с | 0,33 / 8,94 с |
| Пиковая приватная память тестового хоста | 40,06 МиБ | 39,96 МиБ |
| Максимальный размер временных файлов индекса | 7,68 МиБ | 7,68 МиБ |

В обоих форматах получено 262 144 записи, 8 полей, 64 группы, 4 096 записей в `s00`, 1 совпадение в группе и 64 во всём файле. Замеры интерфейса сняты в отдельном Win64-процессе, который загружает собранный WLX через `ListLoadW`. Показатели первых 100 МиБ и временного индекса измерены отдельным запуском того же рабочего потока. Это один измеренный прогон на формат после проверок, системный файловый кеш не очищался. Приватная память включает хост и плагин.

**Дополнительные проверки.** Total Commander 11.55 x64 открыл JSONL на 8 МиБ с индексацией всех 2 048 записей. Пройдены границы 5 МиБ и 5 МиБ + 1 байт, совместимость старого лимита, приоритет нового порога, отмена диалога на 1 ГиБ и при изменённом пороге, UTF-16 LE/BE, UTF-8 с BOM и ANSI, ошибка повреждённой строки, дописывание JSONL и замена файла. Запись на 34 МиБ просмотрена фрагментами. Фильтр нашёл значение за пределами превью. Проверены прокрутка и подсветка в режиме полной загрузки, закрытие во время индексации и очистка временных файлов после закрытия и повторного открытия.

**Границы результата.** Нагрузочная серия подтверждает 1 ГиБ на этом стенде. Порог предупреждения оставлен на 1 ГиБ. Значение 100 МиБ пока оценено по времени до этой отметки внутри большого файла. Потоковый режим сохраняет порядок файла. При вложенности свыше 512 уровней или имени поля свыше 512 КиБ выдаётся ошибка с позицией.

Генератор и измерительные программы — [tests/large-files](../tests/large-files).
